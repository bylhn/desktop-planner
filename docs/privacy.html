한국어

Desktop Planner(이하 "앱")는 Windows 바탕화면에서 쓰는 개인용 플래너입니다. 앱에는 개발자가 운영하는 서버가 없으며, 사용자의 정보를 개발자나 제3자에게 보내지 않습니다.

1. 저장하는 정보

할 일, 고정 루틴, 체크 기록, 설정은 사용자 컴퓨터의 %APPDATA%\desktop-planner\planner-data.json에만 저장됩니다.

2. Google 사용자 데이터 (선택 기능)

접근하는 데이터: 사용자가 "Google로 로그인"을 누른 경우에만 다음 권한을 요청합니다.

  • https://www.googleapis.com/auth/calendar.readonly — Google 캘린더 목록과 일정(제목, 시작·종료 시간) 보기
  • https://www.googleapis.com/auth/calendar.events — 사용자가 앱의 달력 화면에서 입력한 일정을 등록하고, 사용자가 삭제를 누른 일정을 삭제
  • email, openid — 연결된 계정의 이메일 주소

사용 방식: 일정은 앱 화면(오늘의 할 일 옆, 다가오는 일정, 달력)에 표시하는 용도로만 쓰입니다. 이메일 주소는 설정 화면에 연결된 계정을 보여 주는 데만 쓰입니다. 일정은 사용자가 달력 화면에서 직접 등록하거나 삭제를 눌렀을 때만 사용자의 Google 캘린더에 만들거나 지우며, 그 밖의 일정은 수정·삭제하지 않습니다.

저장: 받은 일정은 사용자 컴퓨터에만 캐시로 저장됩니다. 로그인 토큰은 Windows 암호화(DPAPI)로 사용자 컴퓨터에만 저장됩니다.

공유·전송: Google 사용자 데이터를 개발자나 제3자에게 전송·공유·판매하지 않으며, 광고나 AI 모델 학습에 사용하지 않습니다.

삭제: 설정의 "연결 해제"를 누르면 토큰과 캐시된 Google 일정이 삭제되고 Google 쪽 권한도 취소됩니다. Google 계정 권한 페이지에서도 언제든 취소할 수 있습니다. 앱을 삭제한 뒤 위 데이터 파일을 지우면 모든 데이터가 사라집니다.

정책 준수: Desktop Planner가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

3. iCal 주소 연동 (선택 기능)

사용자가 입력한 iCal 주소에서 일정을 내려받아 표시하며, 주소와 일정은 사용자 컴퓨터에만 저장됩니다.

4. 홈페이지 방문 수

이 안내 홈페이지(앱이 아님)는 방문 횟수를 세기 위해 익명 카운터(abacus.jasoncameron.dev)에 숫자 하나를 올립니다. 쿠키를 쓰지 않고 방문자를 식별하는 정보는 저장하지 않으며, 같은 브라우저는 하루 한 번만 세도록 그 날짜만 브라우저에 기록합니다. 앱 자체는 이와 관계없이 어떤 사용 정보도 보내지 않습니다.

English

Desktop Planner ("the app") is a personal planner for the Windows desktop. The app has no developer-run servers and does not send your information to the developer or any third party.

1. Data stored

To-dos, routines, completion history and settings are stored only on your computer in %APPDATA%\desktop-planner\planner-data.json.

2. Google user data (optional)

Data accessed: only when you click "Sign in with Google", the app requests:

  • https://www.googleapis.com/auth/calendar.readonly — view your calendar list and events (title, start and end time)
  • https://www.googleapis.com/auth/calendar.events — add the events you type in the app's Month view, and delete events when you click delete
  • email, openid — the email address of the connected account

Use: events are used only to display them in the app (next to today's to-dos, Upcoming, and the month view). The email address is only shown in Settings to identify the connected account. The app creates or deletes an event in your Google Calendar only when you add it or click delete in the Month view; it never changes any other events.

Storage: events are cached only on your computer. Sign-in tokens are stored only on your computer, encrypted with Windows DPAPI.

Sharing: Google user data is never transferred, shared or sold to the developer or any third party, and is not used for advertising or to train AI models.

Deletion: "Disconnect" in Settings deletes the token and cached Google events and revokes access. You can also revoke access any time at Google Account permissions. Uninstalling the app and deleting the data file above removes all data.

Compliance: Desktop Planner's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. iCal links (optional)

Events are downloaded from the iCal links you enter; the links and events are stored only on your computer.

4. Website visit count

This information website (not the app) adds one to an anonymous counter at abacus.jasoncameron.dev to count visits. No cookies are used and nothing that identifies a visitor is stored; only today's date is kept in your browser so the same browser is counted at most once a day. The app itself sends no usage information.
