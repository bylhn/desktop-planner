바탕화면에 붙어 있는
나만의 스터디 플래너

Desktop Planner는 Windows 바탕화면에 투명하게 떠 있는 플래너예요. 앱을 열지 않아도 오늘의 루틴과 할 일, 캘린더 일정이 늘 보이고, 체크한 기록은 그래프로 쌓여요.

📌

바탕화면 고정

다른 창 뒤, 바탕화면 위에 늘 떠 있어요. 배경화면이 비치는 유리 효과와 투명도 조절.

🔁

고정 루틴

매일 또는 정한 요일마다 다시 생기는 체크리스트로 습관을 관리해요.

✅

오늘의 할 일

그날만 할 일을 시간순으로. 14:00 회의처럼 쓰면 자동 정렬돼요.

📊

달성 대시보드

연속 완수 일수, 30일 달성률 그래프, 20주 히트맵, 루틴별 달성률.

📅

캘린더 연동

Google 캘린더 로그인으로 폰 일정이 함께 보이고, 달력에서 날짜를 누르거나 끌어서 등록한 일정은 폰에도 바로 떠요. iCloud·Outlook iCal 주소도 돼요.

🔔

골라서 받는 알림

일정·할 일에 🔔를 누른 것만 시작 5분 전(10·30분 선택)에 소리 없이 Windows 알림으로 알려 줘요.

🛟

기록은 안전하게

매일 자동 백업(최근 30일). 파일이 깨지면 다음 실행 때 자동 복구되고, 트레이 아이콘은 항상 남아요.

🔄

자동 업데이트 · 한/영

새 버전은 알아서 받아 두고 다시 시작 한 번이면 적용돼요. 한국어·English는 설정에서 언제든 바꿔요.

Calendar

달력에서 일정 다루기

  • 날짜 한 번 클릭 — 아래에 그날 일정 칸이 열려요. 일정이 많으면 스크롤해서 볼 수 있어요. 같은 날짜를 다시 누르거나 맨 위 "오늘" 옆 같은 빈 곳을 누르면 닫히고 달력 전체가 보여요.
  • 날짜 두 번 클릭 — 그날의 하루 화면(루틴·할 일)으로 넘어가요. 열린 칸의 하루 보기 →로도 갈 수 있어요.
  • 할 일 보기 — 달력 칸에는 일정만 보여요. 날짜 옆 작은 할 일 ▾ 버튼을 누르면 그날 할 일이 펼쳐지고 바로 체크할 수 있어요.
  • 일정 등록 — 열린 칸에 14:00 회의(1시간), 14:00-15:30 스터디(시간 범위), 엄마 생일(종일)처럼 쓰고 등록(Enter). Google 캘린더에 바로 들어가서 폰에도 떠요.
  • 여러 날 한 번에 (드래그) — 날짜를 누른 채 다른 날짜까지 끌면 기간이 선택돼요. 시간 없이 쓰면 그 기간 전체에 걸친 종일 일정 하나(예: 3일 여행), 09:00 운동처럼 시간을 쓰면 날마다 같은 일정이 하나씩 들어가요.
  • 삭제 — 일정에 마우스를 올리고 ✕를 누르면 바로 지워지고, 폰의 Google 캘린더에서도 사라져요.
  • 🔔 알림 — 시간이 있는 일정에 마우스를 올려 🔔를 누르면 시작 5분 전에 소리 없이 Windows 알림이 떠요. 등록할 때 입력칸 옆 🔔를 켜 두면 처음부터 알림이 걸려요. 몇 분 전에 알릴지는 ⚙ 설정 → 알림에서 바꿔요.
  • 폰과 동기화 — 폰에서 넣은 일정은 컴퓨터를 쓰는 동안 15분마다, 그리고 플래너를 다시 열 때 바로 받아와요.

Privacy

Google 캘린더 데이터 사용 안내

Desktop Planner는 사용자가 설정에서 "Google로 로그인"을 눌렀을 때만 Google 계정에 연결해요. 요청하는 권한과 사용 방식은 다음과 같아요.

  • calendar.readonly — 내 Google 캘린더의 일정 목록과 일정을 가져와 플래너의 "오늘의 할 일" 옆과 "다가오는 일정", 달력 화면에 표시해요.
  • calendar.events — 달력 화면에서 내가 직접 입력한 일정을 Google 캘린더에 등록하고, 내가 삭제를 누른 일정만 지워요. 그래서 폰에서도 바로 보여요.
  • email — 어떤 계정이 연결됐는지 설정 화면에 보여 주기 위해서만 써요.
  • 일정은 사용자 컴퓨터에만 저장되고, 개발자 서버나 제3자에게 전송되지 않아요. 앱에는 운영 서버가 없어요.
  • 내가 등록하거나 삭제를 누른 일정 말고는 수정·삭제하지 않아요.
  • 로그인 토큰은 Windows 암호화(DPAPI)로 사용자 컴퓨터에만 저장되고, 설정의 "연결 해제"로 언제든 삭제·취소할 수 있어요.
  • Google API로부터 받은 정보의 사용은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수해요.

자세한 내용은 개인정보처리방침을 확인하세요.

Get started

시작하기

  1. 설치 파일 받기 — 위의 다운로드 버튼을 눌러 DesktopPlanner-Setup.exe를 실행하세요. "Windows의 PC 보호"가 뜨면 추가 정보 → 실행.
  2. 루틴과 할 일 추가 — "고정 루틴"의 편집, 아래 입력칸에 할 일을 쓰고 Enter.
  3. (선택) 캘린더 연결 — ⚙ 설정 → Google로 로그인, 또는 iCal 주소 추가.

Good to know

알아 두세요

  1. 무료 · 오픈소스 — Desktop Planner는 무료로 배포되고 코드가 모두 공개돼 있어요(MIT 라이선스). 필요한 기능은 직접 추가해서 쓰셔도 되고, GitHub에 제안해 주시면 다음 버전에 반영할 수 있어요.
  2. 직접 고친 기능과 업데이트 — 설치된 앱 파일을 직접 고치면 업데이트 때 새 파일로 덮어써져 사라져요. 고쳐 쓰고 싶다면 저장소를 포크해서 직접 빌드하고, 새 버전은 GitHub에서 가져와(merge) 합치세요. 업데이트로 화면이나 코드 구조가 바뀌면 직접 추가한 기능이 맞지 않을 수 있고, 이 부분은 보장해 드리기 어려워요.
  3. 내 기록은 안전해요 — 할 일·루틴 기록과 백업은 앱과 따로 저장돼서, 업데이트해도 지워지지 않아요.
  4. 업데이트 안 할 권리 — 새 버전은 기본적으로 알아서 받아지지만, ⚙ 설정 → 자동 업데이트 → 끄기 (알림만)을 고르면 알려만 주고, 받기·설치는 직접 눌렀을 때만 해요.
  5. 코드 서명 없음 — 개인 프로젝트라 설치할 때 Windows가 "PC 보호" 경고를 띄울 수 있어요. 추가 정보 → 실행을 누르면 돼요.
In English

Desktop Planner, in short

Desktop Planner is a free, open-source study planner that lives on your Windows desktop: fixed daily routines, per-day to-dos, a progress dashboard, and optional Google Calendar / iCal events — add events (even across several dragged days) from the Month view and they show up on your phone. Ring the 🔔 on any timed event or to-do for a silent Windows reminder a few minutes before it starts. Daily automatic backups and auto-updates included (you can turn automatic updates off in Settings and only be notified). It's free and open source (MIT): add features yourself or suggest them on GitHub — note that edits made directly to the installed app are replaced by updates, so fork the repository if you want to keep your own changes. When you choose Sign in with Google, the app requests calendar.readonly to display your events, calendar.events to add the events you type in the Month view (and delete the ones you choose), and email to show which account is connected. Events and tokens stay on your computer; nothing is sent to the developer or third parties, and no other events are ever changed. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See the privacy policy and the user guide.
