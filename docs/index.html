바탕화면에 붙어 있는
나만의 스터디 플래너

Desktop Planner는 Windows 바탕화면에 투명하게 떠 있는 플래너예요. 앱을 열지 않아도 오늘의 루틴과 할 일, 캘린더 일정이 늘 보이고, 체크한 기록은 그래프로 쌓여요.

⬇ Windows용 무료 다운로드
Windows 10/11 · 무료 · 오픈소스 (MIT) · 사용 설명서

주요 기능

📌

바탕화면 고정

다른 창 뒤, 바탕화면 위에 늘 떠 있어요. 배경화면이 비치는 유리 효과와 투명도 조절.

🔁

고정 루틴

매일 또는 정한 요일마다 다시 생기는 체크리스트로 습관을 관리해요.

✅

오늘의 할 일

그날만 할 일을 시간순으로. 14:00 회의처럼 쓰면 자동 정렬돼요.

📊

달성 대시보드

연속 완수 일수, 30일 달성률 그래프, 20주 히트맵, 루틴별 달성률.

📅

캘린더 연동

Google 캘린더 로그인, 또는 iCloud·Outlook iCal 주소로 일정을 함께 표시해요.

🌐

한국어 / English

윈도우 언어를 따라가고, 설정에서 언제든 바꿀 수 있어요.

기록이 쌓이면 보이는 것들

할 일과 루틴을 체크할 때마다 날짜별로 기록돼요. 대시보드에서 내가 얼마나 꾸준했는지, 어떤 루틴을 잘 지키는지 한눈에 확인하세요.

Google 캘린더 데이터 사용 안내

Desktop Planner는 사용자가 설정에서 "Google로 로그인"을 눌렀을 때만 Google 계정에 연결해요. 요청하는 권한과 사용 방식은 다음과 같아요.

  • calendar.readonly — 내 Google 캘린더의 일정 목록과 일정을 읽기 전용으로 가져와 플래너의 "오늘의 할 일" 옆과 "다가오는 일정", 달력 화면에 표시해요.
  • email — 어떤 계정이 연결됐는지 설정 화면에 보여 주기 위해서만 써요.
  • 일정은 사용자 컴퓨터에만 저장되고, 개발자 서버나 제3자에게 전송되지 않아요. 앱에는 운영 서버가 없어요.
  • 일정을 수정·삭제·생성하지 않아요.
  • 로그인 토큰은 Windows 암호화(DPAPI)로 사용자 컴퓨터에만 저장되고, 설정의 "연결 해제"로 언제든 삭제·취소할 수 있어요.
  • Google API로부터 받은 정보의 사용은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수해요.

자세한 내용은 개인정보처리방침을 확인하세요.

시작하기

  1. 설치 파일 받기 — 위의 다운로드 버튼을 눌러 DesktopPlanner-Setup.exe를 실행하세요. "Windows의 PC 보호"가 뜨면 추가 정보 → 실행.
  2. 루틴과 할 일 추가 — "고정 루틴"의 편집, 아래 입력칸에 할 일을 쓰고 Enter.
  3. (선택) 캘린더 연결 — ⚙ 설정 → Google로 로그인, 또는 iCal 주소 추가.

English

Desktop Planner is a free, open-source study planner that lives on your Windows desktop: fixed daily routines, per-day to-dos, a progress dashboard, and optional Google Calendar / iCal events. When you choose Sign in with Google, the app requests calendar.readonly and email only to display your events (read-only) and show which account is connected. Events and tokens stay on your computer; nothing is sent to the developer or third parties, and events are never modified. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See the privacy policy and the user guide.
